# Reflection

The most difficult concept in this course was how clients and servers talk using HTTP and APIs. When I first met it, I did not understand the terms: requests, responses, status codes, REST and fetch. I overcame it by splitting the topic into small parts, comparing it to ordering food in a restaurant, and testing real requests in the browser Console and Network tab. Seeing that fetch does not throw an error for a 404 made the idea clear, and building the API client in Project 2 made it stick.

Based on the feedback I received, I would improve two things in my capstone. First, I would connect the API client to a real backend and database, so notes are really saved instead of using a practice API that only pretends. Second, I would check my work more carefully before submitting. A small function-name mistake in my Day 4 assignment, and a paste error that cut off one of my documents, each cost me marks. Now I test my work and check the end of my files before I push to GitHub.

Next, I want to learn backend development with Node.js and a real database, and then a front-end framework such as React, so that I can build and deploy a complete application of my own.
